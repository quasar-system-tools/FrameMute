# Security policy

## Supported version

Security fixes are applied to the latest code on `main`. This project is an early preview and does not publish supported release branches yet.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private security-advisory reporting for this repository, or contact the repository owner privately through GitHub.

Do not attach a real photo, credential, access token, private key, or other personal data to a report. Provide a minimal synthetic reproduction instead.

## Scope notes

The most important security property is that Maskly does not intentionally upload selected photos to a Maskly service. Reports that show a violation of that boundary, unsafe handling of local files, or an avoidable content-security-policy weakness are especially valuable.
